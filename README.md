# Dispatch — News Reader

A clean, editorial-style news reading interface built with HTML, CSS, and vanilla JavaScript.

## Features

- Featured hero story and categorized article grid
- Search, sort, and category filters
- Full-screen reading mode with scroll progress
- Save articles for later (localStorage)
- Dark / light theme
- Responsive layout

## Run locally

Open `index.html` in your browser, or serve the folder with any static server.

## Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript

Sample articles and images are included for demonstration.
